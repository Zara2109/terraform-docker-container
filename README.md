# Terraform Docker Container

## Objective
Provision and manage a Docker container using Terraform Infrastructure as Code.

## Tools
- Terraform
- Docker

## Workflow

Terraform Configuration
↓
terraform init
↓
terraform plan
↓
terraform apply
↓
Docker Container Created
↓
terraform state
↓
terraform destroy

## Commands

```bash
terraform init
terraform validate
terraform plan
terraform apply
terraform state list
terraform destroy
